# WAVC-Dronelock

Дронолок: обнаружение дронов на широкоугольной камере.

## Состав

- [`detector/`](detector/) — прототип быстрого детектора точечных целей на кадрах 16 Мп (Python + OpenCV), демо-прогон, генератор синтетического видео и замеры скорости.
- [`native/`](native/) — то же ядро на C++ с SIMD (AVX2, SSE2, NEON для Raspberry Pi), поиск крупных целей на нескольких масштабах, учёт движения камеры, трекер с прогнозом (фильтр Калмана) и удержанием захвата, классификатор дрон/птица, C-API и обёртка для Python. На 16 Мп в 5–6 раз быстрее Python-версии при тех же результатах.
- [`app/`](app/) — тестовое приложение для Windows: проигрывает видео через детектор (с замедлением и покадрово вперёд/назад), показывает цели по классам, захват и прогноз движения, метрики скорости, позволяет ограничить ресурсы, чтобы имитировать слабое железо.

Сборки для Windows x64 и Raspberry Pi (aarch64, armhf) делает GitHub Actions: вкладка Actions → запуск `build` → артефакты.
